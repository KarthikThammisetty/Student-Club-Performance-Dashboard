Quality Club NIT Jamshedpur — Power BI Dashboard

An interactive Power BI dashboard developed during my internship at the Indian Foundation for Quality Management (IFQM) for the Quality Club at the National Institute of Technology Jamshedpur (NIT Jamshedpur).

The dashboard provides a consolidated view of club membership, student engagement, internship participation, event performance, and attendance. It helps visualize club activities and transform student and event data into meaningful insights for data-driven decision-making.

Project Overview

The dashboard is organized into two interactive pages:

1. Club Overview

Provides an overview of club membership, student feedback, and internship participation.

Key features:

* Membership Analytics: Tracks total members and active members, with a breakdown by academic branch and year.
* Club Performance Ratings: Displays average club ratings, event organization ratings, student engagement ratings, skill development ratings, and event information ratings.
* Internship Analytics: Summarizes internship participation and provides a breakdown of interns by organization.
* Interactive Filters: Allows users to filter membership data by academic year and branch.

2. Event Analytics

Focuses on event participation, student attendance, and event performance.

Key features:

* Event KPIs: Displays the total number of events, club members, average participants per event, and attendance frequency.
* Event Participation Analysis: Compares participant counts across club events.
* Branch-wise Analysis: Visualizes event participation across academic branches.
* Year-wise Analysis: Examines participation patterns across different academic years.
* Interactive Filters: Enables users to explore event data by academic year and branch.

Dashboard Highlights

The dashboard showcases key metrics from the underlying dataset, including:

* Total club membership and active membership.
* Average club and event-related ratings.
* Internship participation and organization-wise distribution.
* Number of events organized and average attendance per event.
* Event-wise participation and attendance patterns.

The dashboard’s KPIs and visualizations provide a consolidated view of club activities and help identify participation patterns and areas for improvement.

Tools & Technologies

* Microsoft Power BI: Dashboard development, interactive visualizations, and KPI reporting.
* Data Visualization: Charts, KPI cards, tables, and interactive slicers.
* Business Intelligence: Membership tracking, event analytics, and performance monitoring.

Business Value

This project demonstrates how business intelligence and data visualization can support student organization management by:

* Improving visibility into club membership and engagement.
* Monitoring event participation and attendance patterns.
* Summarizing student feedback and club performance ratings.
* Tracking internship participation across organizations.
* Supporting informed decisions about future events and club activities.
